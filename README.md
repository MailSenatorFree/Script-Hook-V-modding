# Script Hook V — Native Script Modding Library for Grand Theft Auto V

**The essential modding tool that allows custom script mods to run in Grand Theft Auto V — required for almost every GTA V mod**

Script Hook V is the fundamental modding library for Grand Theft Auto V that enables custom script modifications to run in the game. Created by Alexander Blade, this tool is required by almost every GTA V mod — from simple trainer menus to complex total conversions. Without Script Hook V, most mods simply will not work.

**Step 4: Copy Files**

**Step 5: Launch the Game**

- Script Hook V loads automatically
- The Native Trainer (if installed) opens with F4 key

### What to Do If Antivirus Blocks Script Hook V

Some antivirus programs may flag Script Hook V as suspicious because it hooks into game processes. This is a false positive.

**Solution:**
1. Add the Script Hook V files to your antivirus exclusions
2. Temporarily disable real-time protection during installation
3. Restore the files from quarantine if removed

Script Hook V is 100% safe and has been used by millions of modders worldwide.

## ❓ Frequently Asked Questions

**Q: Is Script Hook V free?**  
A: Yes, completely free to download and use.

**Q: Does Script Hook V work in GTA Online?**  
A: NO — the game will crash or you will get banned. Remove before playing Online.

**Q: Do I need Script Hook V for all mods?**  
A: No — only for script mods (.asi files). Graphics mods and vehicle mods do not require it.

**Q: Is Script Hook V compatible with RAGE Plugin Hook?**  
A: Yes, both work together. Required for LSPDFR.

**Q: How do I uninstall Script Hook V?**  
A: Delete `ScriptHookV.dll` and `dinput8.dll` from your GTA V folder.

**Q: Does Script Hook V work on Steam Deck?**  
A: Not officially supported. May work with Windows emulation.

**Q: Who created Script Hook V?**  
A: Created by Alexander Blade, a legendary GTA modding developer.

**Q: How often is Script Hook V updated?**  
A: Updated within days after every GTA V patch.

**Q: Can I use Script Hook V with FiveM?**  
A: Not needed — FiveM has its own scripting system.

**Q: What is the difference between Script Hook V and Script Hook V .NET?**  
A: Script Hook V is for C++/ASI mods. .NET version is for C# mods (requires both).

**Q: My game says "Unknown game version" — what do I do?**  
A: Wait for Script Hook V update or downgrade GTA V version.

**Q: Is there a version for the Epic Games Store version?**  
A: Yes, Script Hook V works with all PC versions.
